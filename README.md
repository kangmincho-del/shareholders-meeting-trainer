# 주총 진행 트레이너

정기주주총회를 준비·진행·마무리하는 절차를 문제로 익히는 단일 파일 학습 게임입니다.
빌드 도구 없이 `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 서버가 필요하지 않습니다.

## 구성

| 모드 | 내용 |
| --- | --- |
| ① 의장 시뮬레이션 | 14문항. 결산 → 소집 결정 → 소집통지(또는 전원동의 생략) → 개회·정족수 → 의안별 결의 → 보고사항 → 폐회 → 의사록·등기까지 각 단계의 상황을 주고 올바른 진행을 고릅니다. |
| ② 순서 맞추기 | 총회 절차 9단계를 순서대로 배치하고 채점합니다. |
| ③ O/X 퀴즈 | 10문항. 보통결의·특별결의 정족수, 소집통지 기간, 배당 미실시 결의, 의사록 기명날인 등. |

## 다루는 근거 조문

- 제365조 — 정기총회의 소집 시기
- 제362조 — 소집의 결정(이사회)
- 제363조 — 소집통지 기간, 소규모 회사 특례, 전원 동의에 의한 절차 생략
- 제368조 — 보통결의 정족수, 특별이해관계인
- 제373조 — 의사록
- 제388조 — 이사의 보수
- 제396조 — 의사록의 비치
- 제434조 — 특별결의 정족수
- 제449조·제462조 — 재무제표 승인과 이익 배당

## 주의

학습용 자료입니다. 실제 총회 운영과 법률 판단은 회사의 정관과 전문가 검토를 따르십시오.

## 기술

바닐라 HTML·CSS·JavaScript. 외부 의존성 없음. 라이트/다크 테마 자동 대응.
